🔌 Integração com API

Endpoint de Reset de Senha:

GET http://localhost:8080/api/profiles/reset-password Content-Type: application/json Body: { "email": "user@example.com" }

Resposta Esperada:

{ "success": true, "message": "Reset link sent to your email" }

Erro:

{ "success": false, "error": "Email not found" }
⚠️ Nota: A URL está com localhost. Atualize para produção quando necessário.
